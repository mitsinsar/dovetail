Auto-split
Cuts go where the model is thin, not where a grid says
For each axis that's too long for the bed, Dovetail slices the model at 240 positions and records the cross-section area. A dynamic program then picks the cheapest set of cuts that keeps every segment between min part and the bed length. Below: the 520 mm demo rook on a 256 mm bed.
Cost = face areaA smaller cut face means less to glue and fewer connectors. Cutting through empty space is free.
+ edge penaltyCuts just beside a sudden change in the profile (the band on the tower here) would leave slivers, so they cost extra.
+ a pull toward even spacingAmong equal options, parts of similar size win. Room for protruding pegs is reserved so parts still fit the bed.
