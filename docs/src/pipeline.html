How it works
From one oversized STL to print-ready plates
Six steps, all in your browser. The geometry runs on manifold-3d (WebAssembly) in a Web Worker, so the page stays responsive and your file never leaves your machine.
01

Load

Binary or ASCII STL, welded into a solid. Pick mm, cm, inch or µm, or type the real size.

02

Fit check

Your printer preset sets the bed. Margin is kept free; anything bigger is flagged too big.

03

Split

Auto-split places cuts where the cross-section is small. Add or tilt planes by hand.

04

Join

Pegs, dowels or dovetails go on every cut face, sized to fit, with clearance per side.

05

Orient

Each part is laid flat-side down: most bed contact, least overhang, low height.

06

Pack & export

Parts nest on real footprints across plates, then export as one slicer project.

Bambu Studio / OrcaSlicer: one 3MF, plates set up PrusaSlicer 2.9+: one 3MF, beds set up Cura / other: zip, one 3MF per plate or a plain STL zip
